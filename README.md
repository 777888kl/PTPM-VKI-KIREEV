# PTPM-VKI — Лабораторная работа №3

## Тема
Интеграционное тестирование проектов и работа с тестовыми заглушками

## Проект
Вариант «Треугольник» (логика из Лабораторной работы №1).

## Структура

```text
.
├── main.py                 # запуск программы
├── src/
│   ├── calculator.py       # a) вычисления / валидация
│   ├── database.py         # b) работа с SQLite
│   ├── user_interface.py   # c) ввод пользователя (ABC + console)
│   ├── notifier.py         # d) сторонняя зависимость (ABC + email-имитация)
│   └── controller.py       # e) Controller — бизнес-логика
└── tests/
    ├── test_database.py    # тесты БД
    ├── test_stubs.py       # заглушки input / notifier
    └── test_integration.py # интеграционные тесты (>= 3)
```

## Запуск программы

```bash
python main.py
```

Введите три стороны (например `3`, `4`, `5`).

## Запуск тестов

Из корня репозитория (ветка `Lab_3`):

```bash
python -m unittest discover -v -s tests -t .
```

## Что проверяют тесты

| Файл | Тип | Что покрывает |
|------|-----|----------------|
| `test_integration.py` | интеграционные (4 шт.) | Controller + Calculator + DB + заглушки UI/сервера |
| `test_database.py` | модульные | add / get / delete SQLite |
| `test_stubs.py` | модульные + mock | `input()` и отправка на «email-сервер» |

Минимум задания: ≥5 тестов, из них ≥3 интеграционных — выполнено.
Тесты ЛР2 (юнит-проверки классификации треугольника / delivery) не дублируются.
